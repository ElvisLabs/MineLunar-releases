# MineLunar 安装包

这里只放 MineLunar 启动器的安装包，由源码仓库的 GitHub Actions 自动构建发布。启动器会从本仓库的 Releases 自动检查和下载更新。

- **Windows**：下载 `MineLunar-Setup-<版本>.exe` 安装。安装包未签名，Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
- **macOS**：Intel 机型下载 `MineLunar-<版本>-x64.dmg`，Apple 芯片下载 `MineLunar-<版本>-arm64.dmg`。应用未经 Apple 公证，第一次打开请右键选择「打开」。
- **客户端模组**：每个版本的 `minelunar-client-*.jar` 也附在 Release 里（启动器已内置，一般不需要单独下载）。

MineLunar 与 Mojang、Microsoft、Moonsworth（Lunar Client）均无关联。
